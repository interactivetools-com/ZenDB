# Security Policy

Report a security problem in ZenDB privately. Don't open a public issue: until a fix is
released, a public report shows everyone how to attack the sites that use the library.

- **GitHub:** [Report a vulnerability](https://github.com/interactivetools-com/ZenDB/security/advisories/new) on the Security tab
- **Email:** support@interactivetools.com

Include the ZenDB call and the values that show the problem, and the MySQL or MariaDB version.
Only the latest release gets security fixes.
